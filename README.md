# Text Adventure Game 🗡️

Welcome to my first Python text adventure game! In this game, your decisions decide your fate. 

## How to Play
- Run the `text_game.py` script.
- Read the prompts on the screen carefully.
- Type in your choices to navigate through the rooms and fight monsters.
- Type `q` or `quit` at any time to exit the game.

## Features
- 5 unique levels
- Multiple different endings depending on your choices

Can you guess the mystery number and survive the 3-headed hydra? Good luck!
